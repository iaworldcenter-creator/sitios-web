1. **Núcleo de Sistema de Audio (PowerShell + C# / .NET):** Interacción directa de bajo nivel con la API nativa de Windows (CoreAudioAPI).

3. **Capa de Control e Interfaz (Glassmorphic Web UI):** Un simulador interactivo premium estilo Web OS que permite el monitoreo visual, la configuración interactiva y proporciona los accesos rápidos a los comandos del sistema.

  3. Genera un acceso directo de Windows de arranque silencioso (`StartMicVolumeLock.lnk`) en la carpeta `shell:startup`, ejecutando PowerShell con parámetros `-WindowStyle Hidden -ExecutionPolicy Bypass`.
